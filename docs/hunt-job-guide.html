#Quickstart

Four commands from zero to first scan.

# 1. Install dependencies
$ npm install

# 2. Set up an AI provider key (any ONE of these works)
$ node hunt-job.js setup        # guided — or set GEMINI_API_KEY / ANTHROPIC_API_KEY in .env

# 3. Build your profile — fastest: parse your existing resume PDF
$ node hunt-job.js parse-resume ./my_resume.pdf

# 4. Hunt
$ npm run hunt -- --archetype "DevOps Engineer"
Tip: node hunt-job.js with no arguments opens the interactive menu — every feature is reachable from there. No flags to memorize.

#The Workflow

One loop, repeated until you sign an offer.

1Scanlive boards, newest first
2Evaluate10-dim AI score
3Resumetailored PDF
4Applyauto-fill, you submit
5Prepinterview plan
6Trackstatus per app

The full workflow mode (hunt command or menu option) chains steps 1–4: scan → pick a job → evaluate → generate resume → open the application pre-filled in a browser. Jobs posted in the last 48 hours are flagged 🔥 fresh — apply to those first; early applicants get disproportionate recruiter attention.

You are the gatekeeper. Hunt-Job never submits an application by itself. It fills the form, shows you a report of every field, and waits. Review, fix anything, click submit yourself.

#Feature Deep-Dive

📡 Portal Scanner

Hits Lever and Greenhouse public JSON APIs directly — the same data the career page renders, without the career page. 30 verified companies (Stripe, Databricks, PhonePe, CRED, Paytm, MongoDB, Airbnb, Anthropic…), scanned in parallel, results cached in SQLite for 4 hours, stale listings older than 90 days dropped.

🧠 Job Evaluator

Ten dimensions, each scored 1–5: salary alignment, tech-stack fit, culture, growth, location/remote, team, product-market fit, work-life balance, career progression, dealbreaker compliance. Returns matches, mismatches, reasoning, and an Apply / Maybe / Skip verdict. Rule of thumb: don't apply below 4.0.

📄 Resume Generator

Extracts the top ~20 keywords from the JD, rewrites your summary and reorders experience bullets by relevance, renders through an ATS-safe EJS template, and prints to PDF via Playwright. Output lands in data/<Company>_<Role>_<date>/.

🎤 Interview Prep

From any JD: 10+ focus areas, concepts grouped by category (DSA, system design, DB…), likely interview rounds, 10+ behavioral questions, a 4-week study schedule, and curated YouTube links per topic. Saved as styled HTML you can open in the browser.

#Auto-Fill Engine

The part that saves you 15 minutes per application.

When you choose Apply, Hunt-Job detects which ATS the company uses from the URL, opens a real (visible) Chromium window via Playwright, and runs the matching adapter:

PlatformAdapterCoverage
LeverDedicatedFull form + resume upload
GreenhouseDedicatedFull form + resume upload
WorkdayDedicatedMulti-step, account pages vary
SmartRecruitersDedicatedFull form
Everything elseAI genericLLM maps fields → best-effort fill

It also generates a short tailored cover letter and role-fit summary on the fly, fills them where the form asks, uploads your latest resume PDF, then prints a field-by-field report: filled / skipped / uploaded. Browser stays open — you verify and submit.
