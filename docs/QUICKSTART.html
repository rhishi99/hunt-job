Hunt-Job in 10 minutes

Every step: what to type, where to type it, what you should see. Start at step 1; steps 1–4 cost nothing and call no AI.

Where to type: open PowerShell (Start menu → type "PowerShell"). Every command below runs from the project folder, so do step 1 first and keep that window open.

1Go to the project folder

cd E:\vibe-code-projects\hunt-job
You should see the prompt end with hunt-job>.

2Check it runs (help + tests)

node hunt-job.js help
npm test
Help lists commands (run, list, dashboard, calibrate…). Tests end with a pass count and no red "failed".

3Look at jobs already saved (instant, offline)

node hunt-job.js list --new --limit 10
node hunt-job.js gigs --offline
A table of jobs from the local database. gigs shows part-time / contract only.

4Open the dashboard (the pretty part)

node hunt-job.js dashboard

Leave that window running, then open http://127.0.0.1:7777 in your browser.

  • Pipeline – kanban board; drag or move a job between stages.
  • Today – what needs you right now.
  • Prep – interview topics and checklist.
  • Inbox – emails matched to applications, waiting for your OK.
Stop it any time with Ctrl+C in that window.

5Do one full pass, safely (no AI, no saving)

Open a second PowerShell window, do step 1 again, then:

node hunt-job.js run --once --dry-run
Scans company boards, filters, prints how many jobs survive. Nothing is queued and no AI is called.

6Do it for real (uses AI quota)

node hunt-job.js run --once --max-tasks 5
This calls the AI provider set in .env. Your notes say AI_PROVIDER=gemini there overrides the free order, so check .env first if you want to stay on free providers. --max-tasks 5 keeps it small.
Scores 5 jobs, then writes the morning digest to data\digest\<today>.md and shows a Windows toast. Open that file to read it.

7Try one job by hand

node hunt-job.js evaluate "PASTE-A-JOB-URL"
node hunt-job.js resume JOB-ID
node hunt-job.js prep JOB-ID
Score with reasons; then a tailored one-page resume PDF (with a tailor-report.md listing anything it could not verify); then a prep guide. Find job ids in the dashboard or list --json.

8Teach it what you like (feeds the score)

node hunt-job.js label JOB-ID good
node hunt-job.js calibrate
With under 15 good and 15 bad examples it says "Not enough consistent signal". That is expected at first. Later, calibrate --accept adopts the new weights.

9Optional: Gmail outcomes

node hunt-job.js inbox --since 14d --dry-run
Read-only look at recent emails. Needs Gmail IMAP credentials set up first (see README.md). Skip if not set.

10Run it by itself every 3 hours (optional)

powershell -File scripts\install-schedule.ps1
Creates a Windows Scheduled Task HuntJob-Run. Remove it in Task Scheduler if you change your mind.
